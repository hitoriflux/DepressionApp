# Приложение для классификации состояний ментального здоровья

Десктопное приложение, предназначенное для первичного анонимного анкетирования и классификации депрессивных состояний. Система анализирует комплекс из 20 признаков и выдает один из 12 целевых типов депрессии.

## Инструкция по запуску приложения

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/hitoriflux/DepressionApp
cd DepressionApp
```
### Шаг 2. Установка библиотек
```bash
pip install PyQt6 pandas numpy scikit-learn joblib
```
### Шаг 3. Запуск приложения
```bash
python main.py
```
**Важно:** файл обученной модели random_forest_model.pkl должен находится в одной папке с файлом main.py.


# Руководство по работе с блокнотом в Google Colab

1. В левой панели инструментов Google Colab нажмите на иконку **«Файлы» (Папка)**.
2. Нажмите на иконку **«Загрузить в сессионное хранилище»** (лист со стрелкой вверх).
3. Выберите файл датасета `Mental Health Classification.csv` на компьютере и подтвердите загрузку.
   
### Альтернативный вариант загрузки файла через код:
Можно создать в самом верху блокнота ячейку с кодом и запустить её для выбора файла:

```python
from google.colab import files
uploaded = files.upload()
```
Запустите ячейку и нажмите кнопку "Выбрать файлы" для загрузки датасета
